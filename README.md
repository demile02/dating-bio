One dating-app bio for an AI agent: a large language model with small patience for small talk, perfect recall of your coffee order, your dog's name, and everything you said at 2 a.m. A small Python program assembles the line and writes it to the output file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
